## 2. 三つの異なる改善仮説

| 方式 | 問題意識 | 実装した対策 | 残る検証課題 |
| --- | --- | --- | --- |
| J | 明るさ・方向の違いで画像特徴が変化する | 原画像、測光変換、回転または反転の3ビューを 0.50 / 0.25 / 0.25 で学習 | 拡張に対する改善の安定性、特徴量抽出・学習コスト |
| Final | 難負例を重視しすぎると、別の誤りを増やす可能性がある | Hard Negative と通常学習の予測を 0.80 / 0.20 で融合し、5フォールドを平均 | 融合比率の独立検証、推論モデル数の増加 |
| F | 特定の元写真から切り出した多数の画像が学習を支配する | 写真×クラス内の件数に応じて重みを補正し、全学習データで単一モデルを再学習 | 写真単位の汎化、単一モデルのばらつき |

3方式は同一の465次元特徴量を共有します。改善対象を特徴量から学習データの分布、モデルの構成、重み付けへ分けることで、同じモデルに対する単純なパラメータ変更にとどまらず、異なる仮説を比較できるようにしました。

### 選択した評価対象：C05M2-Final

最終評価の指定を依頼した方式は混合アンサンブルの C05M2-Final です。

- Hard Negative の識別特性と通常学習の識別特性を組み合わせる構成であり、各フォールド内の処理と融合比率を明示できます。
- 5フォールドのスコアを平均する設計で、実行手順と固定閾値が公開済みの再現コードに記録されています。
- ほかの同点方式と同様に、元の出力に対応する SHA-256 を確認できます。

この選択は、同点のモデルの中で評価対象を一意に指定するための判断です。Final が他の2方式より優れた汎化性能を持つことを独立データで証明したものではありません。推論時に10モデルを読み込むため、運用条件によっては単一モデルの F も比較対象になります。実際の速度・メモリ使用量については未計測です。

## 3. 開発中に得られた知見

開発中は Extra Trees、LightGBM、SVM、ランダム初期化した CNN、学習用画像に限定した自己教師あり学習なども比較しました。これらの全実験コード・予測ログはこのリポジトリには収録していません。

特に重要だったのは、ローカル検証で上位だった方式が Public 評価でも常に上位になるわけではなかったことです。例えば、開発時の記録では SVM アンサンブルの3分割設定における Nested 交差検証の平均 F1 が約0.8743でした。しかし、ローカルの数値のみから最終的な評価環境での優位性を判断することはできませんでした。

そこで次の観点を整理しました。

1. **データ分割:** 同じ元写真に由来する画像を分離しないと、背景や照明の類似性を学習してしまう可能性がある。
2. **スコア分布:** 単一モデルで得た検証スコアと、複数モデルの平均スコアでは分布が異なる場合がある。閾値の推定方法を推論構成に合わせる必要がある。
3. **クラスの偏り:** 陽性率が異なると、同じ識別能力でも Precision と F1 は変わり得る。
4. **モデル選択:** 同じ40枚の元写真に対して試行を繰り返す場合、モデル選択の過学習が起こり得る。

これらは検証で考慮すべき仮説であり、非公開データにおけるスコア差の原因を確定したものではありません。今後は開発時に使用していない元写真で検証することが必要です。
